# Shravan's Contact Form Frontend

A responsive contact form website created for a TYBCA-B Cloud Computing practical.

## Files
- `index.html` — page structure and contact form
- `style.css` — responsive visual styling
- `script.js` — basic browser-side form validation and confirmation

## Run locally
Open `index.html` in a web browser.

## Important
This is a frontend demonstration. The form does not send or save messages because a backend/database has not been connected yet. Do not enter private information into a demo deployment.
